# 📱 ایده‌ها و تمرکز - نسخه اندروید (Ideas & Focus Android Edition)

نسخه اختصاصی، کاملاً آفلاین و بومی اندروید برای برنامه مدیریت و تمرکز بر ایده‌ها.

## 🚀 ویژگی‌ها
- کارکرد ۱۰۰٪ آفلاین بر پایه حافظه پایدار داخلی گوشی
- زبان بصری سرمقاله‌ای و پشتیبانی کامل راست‌چین (Persian RTL)
- اولویت‌بندی سه‌سطحی و کانون تمرکز هوشمند (Focus Mode)
- بدون نیاز به سرور یا اینترنت
- مصرف باتری ناچیز و شروع به کار آنی
