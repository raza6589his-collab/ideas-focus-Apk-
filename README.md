# 📱 ایده‌ها و تمرکز - نسخه اندروید (Ideas & Focus Android Edition v1.1.0)

نسخه اختصاصی، کاملاً آفلاین و چندزبانه اندروید برای برنامه مدیریت و تمرکز بر ایده‌ها.

## 🚀 ویژگی‌ها
- **پشتیبانی کامل از ۵ زبان**: فارسی (پیش‌فرض)، انگلیسی، عربی، ژاپنی و ایتالیایی با تغییر آنی.
- **تغییر جهت خودکار**: تنظیم هوشمند راست‌چین (RTL) و چپ‌چین (LTR) بر اساس زبان انتخابی.
- **کارکرد ۱۰۰٪ آفلاین**: ذخیره‌سازی محلی و امن روی حافظه دستگاه بدون نیاز به اینترنت.
- **اولویت‌بندی سه‌سطحی و کانون تمرکز هوشمند (Focus Sanctuary)**.
- **بهینه برای لمس**: استانداردهای ارتفاع و راحتی تپ روی موبایل، فونت خوانا و تم تاریک/روشن.
